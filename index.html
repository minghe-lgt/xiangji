    LOCAL PHOTO BUTLER

    照片管家 · 本地自动归类

    选一个本地文件夹，自动筛出今天拍的照片，按类型分文件夹、按规则重命名，再写回你指定的位置。不经过云端。 需要 Chrome / Edge（File System Access）。

    命名与归类规则

    目录 YYYY-MM / 类型 / 例：2026-03 / 人像 /
    文件名 YYYYMMDD_HHmm_类型_地点_序号.ext 例：20260326_1432_人像_西湖_001.jpg
    类型 人像 / 风光 / 夜景 / 街拍 / 静物 / 文档 / 未分类 依据画面特征 + 文件名启发式
    时间 优先 EXIF DateTimeOriginal，否则文件修改时间 默认只整理「今天」的照片
    尚未扫描。点「选择照片文件夹」开始。
